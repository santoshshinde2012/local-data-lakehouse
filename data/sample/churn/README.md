# Renewal bronze samples

Raw events of a monthly AI coding assistant: billing snapshots, invoices, cancel events,
daily usage, cap hits, overage, incidents, tickets and pricing changes. See the
generator's docstring (`scripts/generate_churn_sample.py`) for each file.

- `fixtures/tiny/`: 120 subscriptions (committed)
- `*.csv` here: generated by `make churn-sample` (default 8,000 subscriptions, gitignored)

```bash
make churn-sample
make churn-gold-local   # no Docker
make churn-parity       # Spark SQL vs pandas (needs pyspark + Java 17)
# or: make up && make wait && make churn-e2e
```
